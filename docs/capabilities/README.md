## 编写规范

1. **一个能力一个文件**，命名 `NN-<能力名>.md`，序号递增。
2. 文件结构统一：
   - `## 能力概览`：一段话说清这个能力是什么、给谁用。
   - `## 能力清单`：主表——`| # | 能力点 | 行为说明 | 实现位置 |`，序号逐条。
   - `## 边界与限制`：表——不可为之事、已知缺陷、设计取舍。
   - `## 验证记录`：实测证据（测试名/HTTP 断言/E2E 脚本），让结论可复现。
3. **实证优先**：每条行为必须有代码位置（`file` 或 `file:函数名`）或测试佐证；不确定的标 `[推断]`。
4. 安全相关行为（鉴权/防冒用）单独标注，不与普通功能混写。
