# Karuta 前端交互与文案设计规格（ui-interaction-design）

> 与 `design-system.md` 分工：后者管视觉宪法（色/字/形），本篇管**交互结构与文案**。
> 全部页面的文字线框稿 + 逐条文案规范。Owner 可逐节否决。
> 基线：重构 R1–R4 与 L1–L4 之后的代码现状；标注 `[新]` 者为本规格新增面。

---

## 0. 设计原则（约束全部后续决策）

1. **对局是价值发生地，其余皆准备成本**——动线压缩到"进对局"与"再来一局"。
2. **任何时刻用户能回答三个问题**：我是谁（玩家/旁观/裁判）、我现在能干什么、系统还活着吗。
3. **破坏性操作二次确认，建设性操作直达**——解散要确认，开局要一次点击。
4. **状态后端权威，前端只派生**——UI 状态从已有 WS 事件/快照推导，零新增后端状态（唯一例外 rematch API）。

## 1. 文案系统

### 1.1 品牌语调三层模型

| 层 | 场景 | 语调 | 示例 |
|---|---|---|---|
| **仪式层** | 品牌瞬间/空态/结算/等待 | 和风书卷气 + 轻拟声，可用颜文字与氛围 emoji | `(｡･ω･｡)` `✧` `🌸` |
| **操作层** | 按钮/表单/导航/状态 | 简洁动宾短语，无颜文字 | `复制邀请链接` `开辟战场` |
| **警示层** | 错误/危险/断线 | 平静陈述 + 行动指引，禁卖萌 | `连接中断，重连中…` |

**硬规则**：
- 一个界面同时最多 2 处仪式层文案（防氛围通胀）。
- 错误文案 = 发生了什么 + 我能做什么。禁止只说"失败啦 (>_<)"。
- 按钮文案 ≤ 6 字；主 CTA 允许 8 字（如「原班再来一局!」）。
- 危险操作按钮用具体动词（`解散战场` 而非 `确定`）。

### 1.2 全局文案对照表（现存 → 优化）

| 位置 | 现存 | 改为 | 理由 |
|---|---|---|---|
| 登录失败 | 账号或密码好像不对哦 (>_<) 再试试？ | 昵称或密码不正确 | 警示层禁卖萌 |
| 注册失败 | （动态透传后端） | 后端原文 + 兜底：`注册失败，请稍后再试` | 行动指引 |
| 建房失败 | 战场开辟失败了… (；′⌒`) 再试一次吧！ | 开辟失败，请重试 | 操作层 |
| 加入失败 | 加入失败啦 (>_<) | 加入失败：{后端原因} | 后端原因优先 |
| 游客昵称校验 | 昵称至少2个字符 | 昵称需要 2–20 个字符 | 一次说全边界 |
| 离开确认 | 真的要撤退吗？(｡•́︿•̀｡) 战友们会想念你的！ | 要退出战场吗？对局不会为你暂停 | 陈述后果而非撒娇 |
| 解散确认 | 确定要解散战场吗？所有战友都会被驱逐出去哦 (；′⌒`) | 解散战场？所有成员将被移出，无法撤销 | 后果 + 不可逆 |
| 抢牌成功 toast | 🎉 你抢到了！太厉害了！+1分 (ﾉ◕ヮ◕)ﾉ | ✓ 抢到 +1 | 对局中信息密度优先，装饰交给结算 |
| 抢慢 toast | 😭 被人抢先了！-1分，本首禁止抢牌 (╥_╥) | 慢了一步 −1 · 本首出局 | 同上 |
| 全员出局 | 💀 全员出局！本首自动结束… (°ω°) | 全员出局，本首结束 | 同上 |
| WS 断线 | 重连中…（仅小圆点） | `[新]` ConnectionBanner 横幅 | 状态可见性 |
| 主包 loading | 施法中… 请稍等 (´。• ω •。`) | 卷轴展开中… | 仪式层可保留，统一为一处 |
| 战场 loading | 战场加载中… (｡･ω･｡) 稍等一下 | 战场集结中… | 同上，动词统一 |
| 空牌库 | （插画各异） | 统一 EmptyState 三件套：标题+说明+CTA | 见 §7 |
| 404 | 这片秘境还没有开拓 | 页面不存在或已移动 | 操作层为主，插画保留 |

### 1.3 对局内 toast 文案收敛（RoomPage 系）

对局中每条 toast ≤ 12 字、无颜文字、动词开头。完整清单：

| 事件 | 文案 | 类型/时长 |
|---|---|---|
| card_claimed(me) | ✓ 抢到 +1 | success 1.5s |
| card_claimed(他) | {名} 抢先一步 | info 1.5s |
| card_missed | 无人抢到，本首流局 | info 1.5s |
| grab_wrong(me, 抢错) | 抢错牌 −1 · 本首出局 | fail 2.5s |
| grab_wrong(me, 被抢先) | 慢了一步 −1 · 本首出局 | fail 2.5s |
| grab_wrong(他) | {名} 出局 | info 1.5s |
| grab_banned | 你已出局，等下一首 | info 2s |
| all_banned | 全员出局，本首结束 | info 2s |
| paused/resumed | 已暂停 / 继续对局 | info 1.5s |
| player_joined/offline | {名} 加入 / {名} 离开 | info 1.5s |
| room_closed | 战场解散，即将返回 | info 2.5s |
| kicked | 你被移出战场 | fail 2.5s |
| duel 抢到 | ✓ 已 {己方区/对方区}抢到 | success 1.5s |
| duel 超时 | 超时，歌曲{重新入队/跳过} | info 2s |
| rematch 成功 | 新房已就绪，链接已复制 | success 2.5s |

> 仪式感补偿：把这些 emoji 颜文字的预算**集中到结算页**（名次揭晓、称号、樱花），单点爆发优于全程撒花。

### 4.7 rematch 后端契约（唯一服务端新增）

```
POST /api/rooms/{id}/rematch   Body: {"reinvite": true}   → {"room": Room}
- 仅房主           → 否 403 FORBIDDEN
- 源房间非 end     → 409 ROOM_NOT_ENDED
- 源房间不存在      → 404
- 配置复制: INSERT...SELECT 全量配置列（deck/interval/mode/mask/penalty/
  shuffle/random/duel七字段/training/min_play/multi_audio）
- reinvite=true: 源房间玩家整体迁入新房间(role=player,score=0,online=false)
- 新 code 重新生成;host=原房主
```

## 5. 对局屏（9 帧，P1 核心）

### 5.1 StatusStrip「我的状态条」`[新]`（读牌区正下方，替代现有三提示条）

```
玩家可抢:  ┌──────────────────────────────────────┐
           │ 🎵 可抢牌！点击牌面抢答      本首 23s ⏱ │ ← gold高亮,全屏唯一强提示
           └──────────────────────────────────────┘
已抢到:    │ ✓ 你抢到了 +1 · 等待下一首               │ ← success
本首出局:  │ ✕ 本首出局 · 等待下一首                  │ ← danger/60
旁观:      │ 👁 旁观中                [⚔ 加入战斗]   │ ← info,按钮=joinBattle
裁判:      │ 👑 你是裁判 · 从上方选牌区选择要读的牌    │ ← gold
等待开局:  │ ⏳ 等待房主开始                         │ ← muted
```

派生规则（纯前端，roomReducer 新增 `myRoundStatus: idle|claimed|banned`）：

| WS 事件 | 迁移 |
|---|---|
| `card_start` / `duel_card_start` | → idle |
| `card_claimed`/`duel_card_claimed` 且 winner=me | → claimed |
| `grab_wrong`(me)/`grab_banned`/`duel_grab_blocked` | → banned |
| `room_state` 重连快照 | 从快照重算，不信任本地 |

渲染优先级：裁判 > 旁观 > claimed > banned > 可抢。

## 7. 状态三态与空态规范（P3）

### 7.1 列表三态统一

| 态 | 载体 | 规则 |
|---|---|---|
| loading | `Skeleton`（骨架屏） | 列表页禁用裸 Spinner；骨架行数=3–6 |
| empty | `EmptyState` | **必须带下一步 CTA**（见下表） |
| error | 错误卡 + 重试按钮 | 文案=原因+重试；保留旧数据时降级为顶部细提示 |

### 7.2 空态文案表

| 页面 | 标题 | 说明 | CTA |
|---|---|---|---|
| 战场列表 | 还没有战场 | 开辟一个，把链接发给战友 | 开辟第一个 → |
| 我的牌库 | 牌库空空如也 | 召唤第一张歌牌，配上声音 | 召唤新牌 → |
| 公共牌库(无结果) | 没有找到匹配的歌牌 | 换个关键词或标签试试 | 清除筛选 |
| 我的牌组 | 还没有牌组 | 从牌库挑几张歌牌组一套阵容 | 去牌库 → |
| 邀请码列表 | 还没有邀请码 | 邀请码用于注册新战友 | 生成一个 → |
